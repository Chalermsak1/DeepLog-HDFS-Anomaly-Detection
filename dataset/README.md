# HDFS Dataset Guide

This directory documents the HDFS (Hadoop Distributed File System) log dataset used for DeepLog anomaly detection research and benchmarking.

## Dataset Overview

The HDFS dataset is a widely adopted benchmark in system log anomaly detection, generated by running MapReduce jobs on a 203-node Hadoop cluster at Carnegie Mellon University.

- **Total Blocks**: 575,061 blocks
- **Normal Blocks**: 558,223 blocks (~97.07%)
- **Anomaly Blocks**: 16,838 blocks (~2.93%)
- **Class Imbalance**: High imbalance ratio (~33:1 normal-to-anomaly)

## Directory Structure

```
dataset/
├── README.md                     # This documentation file
└── HDFS_v1/
    ├── HDFS.log_templates.csv    # 29 event templates extracted via Drain parser
    └── preprocessed/             # (Excluded from Git due to size > 100MB)
        ├── Event_traces.csv      # 575,061 labeled event sequences with timestamps (125MB)
        └── anomaly_label.csv     # Ground-truth block labels (Normal vs Anomaly) (18.6MB)
```

The parsed, space-separated sequence splits used for fast reproducible experimentation are located in `examples/data/`:

- `examples/data/hdfs_train`: 4,855 normal training sequences
- `examples/data/hdfs_test_normal`: 553,366 normal evaluation sequences
- `examples/data/hdfs_test_abnormal`: 16,838 anomaly evaluation sequences

| **E6** | `[*]Received block[*]src:[*]dest:[*]of size[*]` |
| **E7** | `[*]writeBlock[*]received exception[*]` |
| **E8** | `[*]PacketResponder[*]for block[*]Interrupted[*]` |
| **E9** | `[*]Received block[*]of size[*]from[*]` |

## Downloading Raw Preprocessed Traces

The raw files (`Event_traces.csv` at 125MB and `anomaly_label.csv` at 18.6MB) exceed GitHub file upload limits. If you need the raw CSV files for downstream research:

1. Download the preprocessed dataset from Zenodo / LogHub:
   - [LogHub HDFS Benchmark](https://github.com/logpai/loghub)
   - [Zenodo HDFS Archive](https://doi.org/10.5281/zenodo.3227177)
2. Place the extracted CSV files under `dataset/HDFS_v1/preprocessed/`:
   ```bash
   mkdir -p dataset/HDFS_v1/preprocessed
   # Place Event_traces.csv and anomaly_label.csv in dataset/HDFS_v1/preprocessed/
   ```

*Note: The included sequence files in `examples/data/` are already complete and sufficient to train, evaluate, test, and analyze the full DeepLog model without needing to download external files.*
